# 美术资源清单

这个目录里现在放的都是**占位资源**，功能可用但视觉是临时的。
你发资源过来时按下面的文件名替换即可，`index.html` / `app.css` / `app.js`
都不需要改。

---

## 必需

### `logo.svg`（或 `logo.png`）
横幅左侧的标识。

- 显示高度 **30px**，宽度自适应
- 背景是深蓝渐变（`#2b7cc4` → `#063a63`），所以图形要用**白色或浅色**
- SVG 优先；用 PNG 的话请给 **@2x**（60px 高）以上，并把
  `index.html` 里的 `assets/logo.svg` 改成 `assets/logo.png`

### `icons.svg`
图标精灵表。所有图标都在这一个文件里，通过 `<use href="assets/icons.svg#id">` 引用。

**替换规则**：保持每个 `<symbol>` 的 `id` 和 `viewBox="0 0 24 24"` 不变，
只替换内部路径。图标必须用 `fill` 上色（会继承 CSS 的 `fill`），**不要用 `stroke`**，
否则缩放时线宽会失真。

需要的 17 个 id：

| id | 用途 | 显示尺寸 |
|---|---|---|
| `rescue` | 分类：救援与恢复 | 20px |
| `gear` | 分类：配置 | 20px |
| `globe` | 分类：通信 / 任务：打开浏览器 | 20px / 26px |
| `stethoscope` | 分类：诊断 / 任务：硬件诊断 | 20px / 26px |
| `factory` | 任务：恢复出厂 | 26px |
| `clock` | 任务：从备份还原 | 26px |
| `files` | 任务：文件救援 | 26px |
| `disk` | 任务：分区管理 | 26px |
| `key` | 任务：Windows 账户 | 26px |
| `wrench` | 任务：修复启动 | 26px |
| `wifi` | 任务：网络设置 | 26px |
| `share` | 任务：网络位置 | 26px |
| `chip` | 任务：内存测试 | 26px |
| `search` | 任务：数据恢复 | 26px |
| `help` | 横幅按钮：帮助 | 14px |
| `reboot` | 横幅按钮：重启 | 14px |
| `power` | 横幅按钮：关机 | 14px |

> 14px 那三个要特别注意——细线条在这个尺寸下会糊，笔画要粗一些。

## 可选

### `banner-bg.png`
横幅右侧的装饰图/纹理，叠在蓝色渐变之上。

- 高度 **62px**，宽度不限（右对齐显示，不平铺）
- 需要透明通道
- 启用方式：在 `app.css` 的 `:root` 里加一行
  ```css
  --banner-image: url("assets/banner-bg.png");
  ```

### `wallpaper.png`
如果之后要做启动画面或空状态背景。当前布局没有用到。

## 配色

主色集中在 `app.css` 顶部的 `:root`，改一处全局生效：

```css
--ibm-blue-1: #2b7cc4;   /* 横幅渐变亮端 */
--ibm-blue-2: #0d4d84;   /* 横幅渐变暗端 + 分类图标 */
--ibm-blue-3: #063a63;   /* 横幅底边 */
--accent:     #0f62fe;   /* 选中态、悬停高亮 */
```

如果你的美术资源有自己的品牌色，把这四个值换掉就行。

## 布局约束

设计时请照顾这两个尺寸：

- **1024×768** —— 救援环境在没有显卡驱动时的保底分辨率。这个宽度下右侧
  说明栏会自动隐藏，左侧导航收窄到 170px
- **1920×1080** —— 常规情况

横幅在高度 ≤700px 时会压缩到 52px，logo 也会跟着缩，所以 logo 在
**24px 高**时也要能看清。
