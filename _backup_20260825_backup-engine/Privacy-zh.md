# KARL'S LIGHT ACCESS 软件隐私政策
## KARL'S LIGHT ACCESS SOFTWARE PRIVACY POLICY

**版本号：V1.1**  
**生效日期：2026年8月25日**

**重要提示：**

KARL'S LIGHT CO., LTD.（以下简称"我们"）高度重视用户的个人信息及数据安全。

本隐私政策用于说明当您使用 KARL'S LIGHT ACCESS 软件（含 Windows 主程序、安装程序及 KARL'S LIGHT ACCESS 救援系统，以下合称"本软件"）时，我们如何处理与您有关的信息。

请您在使用本软件前仔细阅读并充分理解本政策。

本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国民法典》等现行有效法律法规制定。

## 一、总则：本软件是离线软件

本软件的核心功能（系统备份与还原、恢复出厂、文件救援、分区管理、修复启动、硬件诊断等）**不依赖网络连接即可完成**。

**本软件：**

1. **不联网收集、不上传**您的任何个人信息或设备信息；
2. **不内置**用户账户系统、遥测（Telemetry）、广告、统计上报或任何第三方数据收集组件；
3. **不使用** Cookie、设备指纹等跟踪技术；
4. 所有数据处理均**在本机完成**，备份文件保存在**您自己指定的本地磁盘**上。

本软件涉及的少量网络功能（详见第四节）**仅在您主动使用时**才会工作。

## 二、本软件需要的系统权限

本软件涉及磁盘分区、系统镜像捕获与还原、引导管理等底层操作，因此需要以下权限：

| 权限 | 用途 |
|---|---|
| 管理员权限 | 部署救援分区、写入引导文件、磁盘与分区操作 |
| 磁盘读写权限 | 创建救援分区、写入救援系统镜像、保存与读取备份 |
| 卷影副本服务（VSS） | 备份运行中的系统时生成一致性快照，避免文件被占用导致备份失败 |
| 引导配置写入（UEFI NVRAM / BCD） | 安装、更新、卸载 KARL'S LIGHT ACCESS 启动项 |
| 网络访问（仅您主动触发时） | Wi-Fi 连接、网络共享挂载、远程协助、网络代理设置 |

上述权限仅用于实现对应功能。本软件不会将权限用于本政策未说明的用途。

## 三、本软件在本地处理的信息

以下信息**仅在您的电脑本地读取和显示**，用于实现功能，**不会发送给我们或任何第三方**：

| 信息类型 | 具体内容 | 用途 |
|---|---|---|
| 设备与硬件信息 | 电脑品牌、型号、序列号、主板、BIOS 版本、CPU 型号、显卡型号、内存容量、磁盘型号与容量、传感器温度、磁盘健康状态（S.M.A.R.T.） | 硬件诊断、系统概况展示、备份时记录来源环境 |
| 系统信息 | 操作系统版本、内核版本、固件类型（UEFI/Legacy）、安全启动状态 | 判断部署与修复方案 |
| 备份元数据 | 备份时间、范围、大小、来源系统版本 | 备份索引（index.json），供还原时选择还原点 |
| 您主动提供的凭据 | Wi-Fi 密码、网络共享（SMB）地址与账号密码、SSH 协助密码 | 见第四节 |

**关于备份内容：** 备份会捕获您系统分区内的文件（含个人文件，视备份范围而定）。备份文件（WIM 格式）保存在**您指定的本地磁盘**的 `KLA` 目录下，受该磁盘自身的访问权限保护。您可随时在文件管理器中直接删除备份文件。

## 四、网络功能与您提供的凭据

以下功能**只有您主动操作时**才会联网，且各自的数据处理方式如下：

1. **Wi-Fi 连接**（救援系统）：您输入的 Wi-Fi 密码交由系统网络管理器（NetworkManager）用于建立连接。救援系统运行在内存中，**重启后环境销毁，凭据随之消失**（若您将连接配置导出到磁盘则由您自行保管）。
2. **网络共享挂载（SMB）**：您输入的服务器地址与账号密码仅用于本次挂载访问，不写入任何持久存储。
3. **SSH 远程协助**（救援系统）：仅在您主动开启后工作，协助密码只保存在本次运行的救援环境中，关机或重启后失效。
4. **网络代理设置**（救援系统）：代理地址仅在本机网络栈生效，帮助在受限网络环境下访问系统资源。
5. **浏览器**（救援系统）：救援系统内置浏览器访问的网站由您自行决定，各网站的隐私政策适用于对应网站。

## 五、本地配置与日志文件

本软件在以下位置保存配置与日志，均为**本地文件**，可随时手动删除：

| 位置 | 内容 |
|---|---|
| `%ProgramData%\KLA\settings.json` | 协议同意状态、首次引导完成状态（不含个人数据） |
| `%ProgramData%\KLA\bin\` | 备份引擎（wimlib）程序文件 |
| `KLA` 目录（您指定的备份磁盘） | 备份文件与备份索引 |
| 部署/卸载日志 | 排查安装问题用的本地日志 |

卸载本软件时，程序文件、引导项与配置将被移除；**您的备份文件只有在您明确确认后才会删除**，否则保留在原处供您自行处理。
